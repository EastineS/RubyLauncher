# Rubycon Emotes

Forge-мод эмоций персонажа для ролевых серверов на Minecraft **1.20.1 / Forge 47.4.10+**, Java 17.
30 эмоций в духе HSR / Genshin. Каждая эмоция — небольшая эмблема справа сверху от головы
(цветная стеклянная пластина, тонкий золотой ободок, белый глиф), чтобы не мешать нику,
и сдержанный эффект под настроение: искры, лепестки, ноты, румянец, слёзы, капля пота.
Реквизита вроде рук и очков нет. Метки на лице освещаются миром, как кожа; эмблема мягко
догоняет голову при движении. Вся графика своя, её генерируют скрипты из `art/`.

```
rubycon-emotes/
  mod/          исходники мода (Gradle, ForgeGradle 6)
  art/          генераторы графики, анимаций, иконок, превью и .bbmodel
  blockbench/   по одному .bbmodel на эмоцию (полная модель игрока + кадр эффекта)
  docs/         превью на модели игрока и скриншоты из реального клиента
```

## Управление

* **G** — короткое нажатие открывает меню, удержание — колесо из 8 избранных
  (отпустить на секторе — показать, в центре — отмена).
* **Кнопка в чате** — справа в поле ввода любого чата на базе `ChatScreen`
  (ванильный, `RubyconChatScreen`, `NativeRoleplayChatScreen` из Rubycon UI).
  ЛКМ — быстрый выбор с живым предпросмотром, вкладки «Все» / «Избранное»;
  ПКМ по кнопке — полное меню; ПКМ по эмоции — в избранное.
* **Меню** — сетка всех эмоций, предпросмотр на своём скине (вращение мышью,
  переключатель шлема), избранное и порядок секторов колеса, отмена, настройки.
* Команды: `/emote <id>`, `/emote stop`, `/emote list`.

## Сервер

Сервер — источник истины: проверяет id, перезарядку, длительность, режим игры и измерение,
рассылает состояние наблюдателям (`TRACKING_ENTITY_AND_SELF`). Игрок, вошедший в зону
видимости во время эмоции, видит её остаток, а не перезапуск. Эмоция снимается при смерти,
выходе, смене измерения/режима. Конфиг `world/serverconfig/rubycon_emotes-server.toml`:
`enabled`, `allowed`, `cooldownMs`, `maxDuration`, `displayDistance`, `disabledDimensions`,
`disabledGameModes`; изменения подхватываются без перезапуска и синхронизируются клиентам.

Клиентский конфиг: показ чужих/своих эмоций, индикатор от первого лица, масштаб, уменьшенная
анимация (без тряски и мерцаний), кнопка в чате, избранное.

## Рендер

* Слой `EmoteLayer` на модели игрока. Эмблемы и частицы — биллборды у головы (`above`),
  не поворачиваются вместе с ней и с небольшой задержкой следуют за движением.
* Метки на лице (`face`/`head`) рисуются с освещением сущности и смещением глубины,
  поэтому ночью они не светятся и не мерцают на коже.
* Эмблемы и искры — без освещения, с аддитивным ореолом; тест глубины без записи.
* Шлем: метки на лице сдвигаются наружу; невидимые игроки и наблюдатели эмоций не
  показывают; дистанция ограничена сервером.
* Бюджет: при более чем 10 эмоциях в кадре второстепенные частицы прореживаются;
  объекты пула переиспользуются, аллокаций на кадр нет.

## Формат эмоции

`assets/<ns>/emotes/<id>.json` — ресурспак может добавить или переделать эмоцию без кода
(серверу нужен id в `data`-индексе `rubycon_emotes/index.json`). Слой — либо деталь
(`tex`, `anchor`, `pos`, `size`, `keys` с ключами `x y s sx sy rot a`, модификаторы
`pulse beat squash bob sway spin shake flicker seq`, `glow`, `mirror`, `helmet`), либо
эмиттер (`mode`: `stream`/`burst`/`orbit`, `rate`/`times`/`every`, `life`, `speed`, `dir`,
`spread`, `gravity`, `curve`, `stretch`, `wobble`…). Значения и порядок вычислений
описаны в `art/anim.py`; `EmoteAnimator.java` — его построчное зеркало, поэтому превью
совпадают с игрой (проверено скриншотами клиента).

## Графика и пайплайн

```
cd art
python3 sprites.py     # глифы, пластины, частицы, метки на лице -> textures/emote, textures/fx
python3 defs.py        # 30 JSON-эмоций, индекс, названия в lang
python3 preview.py icons x            # иконки меню = эмблемы (badge.py)
python3 preview.py overview out.png   # все эмоции на модели игрока; timeline / gif DIR
python3 bbmodel.py     # blockbench/*.bbmodel
```

Требуются Python 3.10+, Pillow, NumPy. `sdf.py` — общий SDF-рендер с суперсэмплингом.
Цвет эмблемы подобран под эмоцию, без привязки к «стихиям»; превью рисуется на полной
модели игрока с собственным скином 64×64 (стандартная развёртка), а в игре — на вашем скине.

## Сборка и проверка

```
cd mod
./gradlew build                        # build/libs/rubycon_emotes-1.0.0.jar
./gradlew runServer                    # выделенный сервер (run-server/)
./gradlew runClient -Pautotest         # сценарий: все эмоции + UI, скриншоты в run/screenshots
./gradlew runClient -Pautotest -PwithRubycon   # то же с Rubycon UI (положить jar в mod/libs/)
```

`-Pautotest` включает `DevAutotest` (только по системному свойству, в обычной игре неактивен)
и ожидает мир `run/saves/test`.

Мод нужен и на сервере, и на клиенте. Клиент без мода на сервере без мода — кнопка и меню
сообщат, что сервер эмоции не поддерживает.
